# Install
Besides Flathub, Untix is also available in the [AUR](https://aur.archlinux.org/packages/untix) for Arch Linux users:

```
yay -S untix
```
[![Packaging status](https://repology.org/badge/vertical-allrepos/untix.svg)](https://repology.org/project/untix/versions)

# Dependencies
- gettext
- gstreamer 
- gtk4
- libadwaita
- libportal
- libsecret
- python3
- python3-gobject
- python3-pillow
- python3-pyotp
- python3-requests
- python3-zxing-cpp
- webkitgtk-6.0

# Build
To build, clone this in GNOME-Builder and press play.
